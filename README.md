# VendorEcommerceProject

## Vendor Ecommerce System (C#)

A basic vendor ecommerce backend project built using **C#** and **.NET**. This repository includes the core solution structure, entity models, and database schema for a vendor-oriented ecommerce system without a full frontend UI.

---

## Project Overview

This project is designed as a foundational ecommerce system structured with C# and .NET. It focuses on modeling ecommerce domains such as products, vendors, users, orders, and payments. While the frontend interface is not included, the solution setup and database schema demonstrate the backend design and object modeling for an ecommerce application.

---

## Key Features

- **Vendor & Product Models** – Supports basic vendor and product definitions  
- **Order & Cart Structure** – Defines ecommerce order and cart relationships  
- **User Details Management** – Includes customers and related data  
- **Payment Schema** – Basic handling of payment structures  
- **.NET Solution Structure** – Organized codebase for ecommerce backend  

---

## Technologies Used

- **Language:** C#  
- **Framework:** .NET (Visual Studio Solution)
